# Currency Converter

Multi-currency converter with live rates from the
[Frankfurter API](https://frankfurter.dev).

**Live demo:** [currency.domenurh.com](https://currency.domenurh.com)

- `pwa-version/` — the maintained Progressive Web App (TanStack Start, React,
  Tailwind). Start here; see [pwa-version/README.md](pwa-version/README.md).
- `react-native-version/` — earlier Expo port, not actively maintained.
- `flutter-version/` — placeholder.
